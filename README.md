# FastFX

This repository hosts customer-facing **release downloads** for the FastFX Premiere Pro plugin.

For the actual source code, see the private `fastfx-source` repository.

## Latest release — FastFX 2.0.0

**Download:** https://github.com/jakobrowley/fastfx/releases/latest

One version for all platforms. The zip contains the signed `.zxp` and install
instructions (`READ ME FIRST.txt`). Existing license keys keep working.

Older releases (`1.1`, `1.0.7`, `v1.6.0`) are kept only so previously-emailed
links don't break — do not use them for new installs.
